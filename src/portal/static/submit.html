Submit a claimset

Choose a submission package (a .zip made by claimset package) or a claimset file (.json), then submit. It is checked at once. If it is valid, you get a consent link for its guarantor, who signs in with ORCID and confirms within 48 hours; then it is published.

A new version of a published claimset sets paper.id to its identifier.

Agents submit through the API or the MCP server: see /llms.txt.
