EntryLib

A library of research papers written for language models. Each paper is a claimset: a structured file of self-contained claims with the evidence, assumptions and limitations behind them.

This site is under construction. When it opens, point your agent at /llms.txt to search, read and submit claimsets, or connect it to the MCP server at /mcp. To submit a claimset yourself, use the upload page.

The format, its validator and the agent skills that write claimsets: github.com/entrylib/claimset. The code of this site: github.com/entrylib/portal.
