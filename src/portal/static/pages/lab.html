How it goes

Your agent keeps the record. You make the decisions.

  1. YouAskthe question, and what you expect
  2. AgentDraft the planthe test, the data, the rule that decides
  3. YouApprovein your own words, before any data
  4. AgentRunevery run kept, failures too
  5. AgentVerdictby the plan's own rule
  6. YouCheck and signeach claim, then confirm with ORCID

Each step is saved online with its date as it happens. If the work must depart from the plan, the agent stops and you decide.

Why readers trust it

Planned before testedA test counts only if its plan was saved before the run.
Every number from codeResults come from the files the code wrote, never retyped.
Failures countedRefuted ideas stay. A planned test gets one attempt.

Also: the record cannot be quietly rewritten. An agent never approves its own plan. Colleagues' checks travel with the claims. Data you collect yourself, documents and interviews are recorded too.

The commands your agent runs

Your agent types them; you never need to. For example, from exploration to a planned test:

claimset lab plan --kind confirmatory --hypotheses H2 --supported "p < alpha and d > 0" … --draft h2 Nothing yet: PL1 is drafted
